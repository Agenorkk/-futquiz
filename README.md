# FutQuiz ⚽

Quiz de futebol responsivo em português, feito em HTML, CSS e JavaScript sem dependências de instalação.

## Como jogar
Abra `index.html` em um navegador ou publique o repositório com GitHub Pages.

## Publicar gratuitamente com GitHub Pages
1. No repositório, abra **Settings**.
2. Entre em **Pages**.
3. Em **Build and deployment**, escolha **Deploy from a branch**.
4. Selecione a branch **main** e a pasta **/ (root)**, depois clique em **Save**.
5. Aguarde a publicação. O endereço normalmente será `https://agenorkk.github.io/-futquiz/`.

O progresso fica salvo no armazenamento local do navegador/dispositivo. O site não precisa de conta nem de servidor para jogar.
